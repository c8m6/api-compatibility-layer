# Contributing

Contributions and pull requests are welcome.

Develop changes on a branch, keep commits focused, and use Conventional Commits.
Update tests and documentation together with behavior changes. Before opening a
pull request, run the repository's complete documented validation suite.

By submitting a contribution, you confirm that you have the right to submit it
for distribution under Apache-2.0. Do not submit proprietary API documentation,
production configuration, credentials, internal endpoints, or third-party
material whose license is incompatible with the project.

The project does not require copyright assignment or a Contributor License
Agreement. Contributors retain ownership of their contributions.

Security vulnerabilities should be reported through the process documented in
SECURITY.md rather than through public issues.
